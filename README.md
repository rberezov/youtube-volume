# YouTube Exponential Volume

Chrome-расширение, которое делает регулировку громкости в YouTube
**экспоненциальной** и заменяет стандартный короткий ползунок на
**длинный и точный**.

## Зачем

Стандартный ползунок YouTube меняет громкость линейно, а слух воспринимает
её логарифмически. Из-за этого почти весь полезный диапазон сжат в первых
10–20% шкалы: чуть сдвинул — уже громко. Расширение применяет степенную
(экспоненциальную по восприятию) кривую:

```
громкость на выходе = (позиция ползунка)^γ,   γ = 3 по умолчанию
```

Например, при γ = 3 позиция 50% даёт 12.5% амплитуды — субъективно это
как раз «половина громкости».

## Возможности

- Экспоненциальная кривая громкости с настраиваемой крутизной γ (1–6).
  Работает для любого способа изменения громкости: ползунок, стрелки
  ↑/↓, колесо мыши над плеером.
- Длинный ползунок прямо в панели плеера вместо стандартного, с шагом
  **0.1%** и индикатором процента.
- Длина ползунка настраивается (2–70% ширины плеера, по умолчанию 20%)
  и масштабируется вместе с плеером; отступ по краям рамки —
  фиксированная константа, которая один раз вычисляется из размеров
  плашки и дальше не меняется. Толщина полосы, бегунок и подпись растут
  вместе с плеером. Если в панели не хватает места
  (длинное название главы, узкое окно), ползунок укорачивается, затем
  скрывается подпись с процентами, а в совсем узком плеере возвращается
  штатный ползунок YouTube — управление никогда не «разъезжается» и
  громкость всегда остаётся регулируемой. Экспоненциальная кривая
  действует и на штатный ползунок.
- Автосворачивание (настройка «Сворачивать шкалу без курсора»): когда
  мышка не на шкале, остаётся ровный круг со значком по центру — как
  штатные круглые кнопки YouTube; при наведении шкала плавно
  разворачивается. Клавиатурный фокус (Tab) тоже удерживает её
  развёрнутой, а фокус от обычного клика — нет.
- Колесо мыши над ползунком: ±1%, с зажатым Shift — ±0.1%. Заполненная
  часть шкалы — белая, как у штатного ползунка YouTube, и её граница
  считается по фактическому положению центра бегунка (он ходит в
  пределах `[бегунок/2, ширина − бегунок/2]`, поэтому заливка «в
  процентах от ширины» отставала бы тем сильнее, чем ближе к краям).
- Без треска при регулировке: громкость применяется через Web Audio
  (`GainNode.gain.setTargetAtTime` с постоянной времени 15мс), то есть
  усиление меняется в аудиопотоке с частотой дискретизации, а не
  ступенчато на границах буферов, как при записи в `video.volume` из
  JS. Сам элемент при этом держится на максимуме, уровень задаёт
  усилитель. Обойдены известные ограничения Web Audio: DRM-потоки
  (там `createMediaElementSource` даёт тишину) не подключаются вовсе,
  подключение происходит только когда `AudioContext` реально запущен
  (после жеста пользователя), а на случай неожиданной тишины есть
  сторож на `AnalyserNode`, возвращающий прямое управление громкостью.
  Запасной путь без Web Audio — подводка таймером. Сохранение громкости
  в настройках YouTube (`player.setVolume`) — отложенно после остановки
  и целым числом.
- Настройки в popup пишутся в `chrome.storage.sync` отложенно (250мс
  после последнего изменения): у sync-хранилища квота ~2 записи в
  секунду, и запись на каждое событие перетаскивания ползунка настроек
  молча отбрасывалась квотой — включая финальное значение. Доставка
  настроек на страницу самовосстанавливающаяся: content script раз в
  секунду переспрашивает их у bridge.
- Подсказка при наведении показывает и позицию, и фактическую громкость
  на выходе.
- Кнопка mute и ползунок находятся в одной рамке. Значок — один
  собственный, в стиле оригинального плеера: те же формы (viewBox 36×36
  — рупор, одна и две дуги, перечёркивание), заливка `currentColor` с
  тонкой тёмной обводкой. Клонировать SVG у штатной кнопки нельзя: в
  новом интерфейсе она содержит формы сразу нескольких состояний, а
  переключают их классы на самой кнопке — в копии состояния
  накладывались друг на друга. Состояния анимированы: дуги появляются и
  уходят от рупора, перечёркивание прочерчивается штрихом. Кнопка
  занимает почти всю высоту рамки, как штатная; центровка и размер не
  зависят от внутренней раскладки YouTube; клик идёт через официальный
  API плеера
  (`mute`/`unMute`), горячая клавиша M работает как раньше. Штатные
  кнопка и ползунок скрываются, опустевшая «пилюля» — тоже; в режиме
  отката (узкий плеер) всё штатное возвращается.
- Подсветка рамки при наведении — как у штатных «пилюль» YouTube:
  внутренний скруглённый слой с одинаковым пиксельным зазором со всех
  четырёх сторон (константа, вычисляется один раз из размеров) и
  скруглением, уменьшенным на величину зазора, — контуры концентричны. Оформление рамки
  копируется с реально видимой плашки той же строки: собираются все
  элементы с непрозрачным фоном правдоподобной высоты (у обёрток
  YouTube фон бывает и прозрачным, и растянутым на всю строку), а
  образцом берётся самый низкий — настоящая плашка всегда компактнее
  обёрток. Внутри рамки отступ одинаков со всех сторон: кнопка mute
  занимает квадрат «высота минус два отступа» и центрируется вместе со
  шкалой и процентами. Запас ширины подписи распределяется поровну на
  обе стороны.
- Отступы рамки масштабируются вместе с её высотой (то есть с размером
  плеера), подпись с процентами ужата ровно под «100%», чтобы рамка не
  «гуляла» по ширине при изменении значения.
- Режим без отображения процентов (настройка «Показывать проценты»):
  подпись убирается, рамка становится компактнее, освободившееся место
  учитывается при расчёте длины ползунка; точное значение остаётся в
  подсказке при наведении.
- Рамка панели не «раздувается» при наведении: расширение запрещает
  области громкости резервировать ширину под скрытый штатный ползунок,
  а изменения размеров рамки отслеживаются через `ResizeObserver` и
  пересчитываются немедленно.
- Настройки в popup расширения, синхронизируются через профиль Chrome.

Для YouTube всё выглядит как обычная громкость: проценты в интерфейсе и
сохранённое значение не меняются, кривая применяется только к звуку.

## Установка

1. Скачайте/клонируйте этот репозиторий.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика** (справа сверху).
4. Нажмите **Загрузить распакованное расширение** и выберите папку
   репозитория.
5. Откройте (или обновите) вкладку с YouTube.

## Как это устроено

- `main.js` — content script в MAIN-мире страницы. Весь DOM строится
  через DOM API без `innerHTML`: на youtube.com действует Trusted
  Types CSP, и строковые присваивания в HTML-свойства бросают
  исключение. Скрытие штатных элементов громкости включается классом
  `ytev-active` только после успешного монтирования блока расширения —
  при любом сбое штатная громкость остаётся на месте. Подменяет сеттер
  `HTMLMediaElement.prototype.volume`: «логическое» значение, которое
  выставляет YouTube, сохраняется и возвращается геттером, а в аудиотракт
  уходит `значение^γ`. Он же встраивает кастомный ползунок в
  `.ytp-left-controls` плеера и скрывает стандартный (кнопка mute
  остаётся). Ползунок ставится рядом со штатной «пилюлей» кнопок (в неё
  вставлять нельзя: YouTube управляет её шириной из скриптов под её
  собственное содержимое, и содержимое вылезало бы за фон), а рамку
  рисует сам, копируя оформление соседней пилюли с живого элемента —
  фон, скругление, высоту и blur; в старом интерфейсе фон прозрачный,
  прозрачным становится и блок. Длина пересчитывается через
  `ResizeObserver` по ширине плеера с ограничением по свободному месту
  в строке управления: расчёт идёт от ползунка вверх до строки через
  любое число обёрток, на каждом уровне вычитая соседей с отступами.
  Замер делается при ползунке, сжатом до минимума, — иначе результат
  зависел бы от текущей длины (соседние элементы тоже сжимаются) и
  размер бы «дрожал».
- `bridge.js` — content script в isolated-мире: читает настройки из
  `chrome.storage.sync` и пересылает их в `main.js` через
  `window.postMessage`.
- `popup.html` / `popup.js` — настройки: вкл/выкл кривой, γ, длина
  ползунка, проценты, автосворачивание.
